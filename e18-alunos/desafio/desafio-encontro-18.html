O status das solicitações numa constante

Faça com o Status das solicitações o que fizemos com o TipoServico e a Prioridade:

  • No constantes.ts de solicitações, crie o objeto Status com as const (ABERTA, EM_ATENDIMENTO, CONCLUIDA, CANCELADA) e tire o tipo dele.
  • No tipos.ts, o Status escrito à mão sai; ele passa a vir da constante.
  • Troque os textos "aberta", "em-atendimento", "concluida" e "cancelada" pela constante no nomes.ts, no regras.ts e no DetalheSolicitacao.tsx.

Dica: para achar todos os lugares, use a busca do VS Code (Ctrl + Shift + F) com cancelada, sem as aspas: assim ela acha também as chaves do nomes.ts e do regras.ts. Não mexa na pasta ordens-servico: as ordens têm os status delas.

Antes de dar por pronto

Rode npm test, npm run lint e npm run build. No Chrome, entre como Carlos, abra uma solicitação aberta e confira os botões “Iniciar atendimento” e “Cancelar”.
