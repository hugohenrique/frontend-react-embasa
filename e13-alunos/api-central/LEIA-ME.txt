API DA CENTRAL (versão do encontro 13)

Uma API REST do curso, com banco de dados SQLite. NÃO é a API da Embasa.
Usa só o Node (22.13 ou mais novo): não precisa instalar nada.

O QUE MUDOU DESDE O ENCONTRO 12
As ordens de serviço e as equipes de campo (arquivo ordens.mjs), fictícias.
Na primeira vez que roda, a API cria uma ordem para cada solicitação
que já está em atendimento ou concluída.

COMO ATUALIZAR (slide 6 da aula)
1. Pare a API (Ctrl + C no terminal dela).
2. Copie os arquivos desta pasta para dentro da sua pasta api-central,
   substituindo os que já existem. A sua pasta dados continua lá.
3. Rode:
     npm run api

QUEM AINDA NÃO TEM A API
Copie esta pasta para dentro de central-de-solicitacoes, ao lado da src,
acrescente no package.json, dentro de "scripts":
     "api": "node api-central/servidor.mjs"
e rode:
     npm run api -- --volume 5000

Para voltar aos dados iniciais: npm run api -- --reiniciar --volume 5000
O que a API aceita e devolve está em CONTRATO.md.
