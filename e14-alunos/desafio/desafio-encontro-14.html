O componente Campo

No FormularioOrdem, cada campo repete o mesmo desenho: uma div com a classe campo, o label, o campo e, se houver, o erro embaixo. Crie em src/shared/ui um componente Campo que cuide dessa parte:

  • Props: id, rotulo, erro (opcional) e children, que é o input ou o select.
  • O erro aparece num parágrafo com a classe erro-campo e o id {id}-erro, o mesmo que o aria-describedby do campo aponta.
  • Use o Campo nos três campos do FormularioOrdem.

Para testar: na aba de ordens, tente criar uma ordem para a 26-08817, sem equipe e com uma data no passado. Os três erros aparecem embaixo dos campos, como antes.
