Valores e tipos

  

    
"Ana"Texto: string. Entre aspas.

    
1042Número: number. Sem aspas.

    
true falseVerdadeiro ou falso: boolean

    
null undefinedAusência de valor

Variáveis: dar nome a um valor

  

  

    
const
O padrão. O nome não troca de valor.

    
let
Quando o valor precisa mudar. Evite o antigo var.

  







  
Para comparar, use três iguais

  

    
1042 == "1042"true. O == converte os tipos antes de comparar.

    
1042 === "1042"false. O === compara valor e tipo.

  

  
Use sempre === e !==. Sem surpresas.

Mudar a página

  

    
.textContentO texto de um elemento: ler ou trocar

    
.valueO que a pessoa digitou em um campo

    
.classList.add("x")Acrescenta uma classe, e o CSS faz o resto

Texto digitado vira texto, nunca HTML

  

    
textContent
Mostra exatamente o que a pessoa digitou, como texto.

    
innerHTML
Interpreta como HTML. Se alguém digitar código, ele roda na página.

  

  
Com dados digitados ou vindos de fora, use textContent.
