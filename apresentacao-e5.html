Passo 1

Node.js: JavaScript fora do navegador

O que é

Um programa que roda JavaScript no seu computador, sem navegador.

Por que precisamos

As ferramentas de front-end são escritas em JavaScript. Sem o Node, elas não rodam.

Junto vem o npm: ele baixa ferramentas e bibliotecas.

LTS: a versão para trabalho

v24LTS em manutençãosó correções
v26LTS ativadesde 28/10/2026, suporte até abril de 2029
v27Em desenvolvimentonovidades em teste

Long Term Support: estável, com correções por anos. Para trabalho, sempre a LTS.

Etapa 1: passo a passo, como montar

    
React: como a linha deve ficar

  







  
JSX: parece HTML, é JavaScript

  

  
O Vite transforma cada tag numa chamada de função. Por isso o arquivo é .tsx: TypeScript com JSX.







  
Componente: função que devolve JSX

  

  

    
Nome com maiúscula
É assim que o React diferencia <Cabecalho /> de <header>.

    
Usa como tag
<Cabecalho /> no lugar onde ele deve aparecer.

  







  
Quatro diferenças do HTML

  

    
<> … </>Um único elemento por fora. O fragmento agrupa sem criar tag.

    
{/* … */}Comentário. <!-- --> não existe no JSX.

    
className, htmlForclass e for são palavras do JavaScript.

    
tabIndex={0}Atributos em camelCase. Número e expressão vão entre chaves.

  

  
E toda tag fecha: <input />.

Props: os dados que o componente recebe

  

  
Como atributos de uma tag. O componente recebe todos juntos, num objeto.







  
Props com tipo

  

  
O type da sexta descreve as Props. A desestruturação do encontro 3 tira cada uma do objeto.







  
Chaves: JavaScript dentro do JSX

  

  
Entre chaves vai qualquer expressão: uma variável, um objeto consultado, uma função chamada.
