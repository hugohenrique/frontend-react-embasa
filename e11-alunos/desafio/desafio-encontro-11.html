Um resumo por status

O supervisor quer bater o olho e saber como está o dia. Acima dos filtros, no cartão “Solicitações recentes”, mostre quatro cartões: quantas estão abertas, em atendimento, concluídas e canceladas.

  • No regras.ts, uma função pura contarPorStatus(lista), que devolve um Record<Status, number>.
  • Um componente de apresentação ResumoStatus, que recebe a contagem por Props.
  • O resumo precisa se atualizar sozinho quando o atendente inicia ou conclui uma solicitação no painel.

Dica: se a contagem for calculada a partir da lista da página, ela se atualiza sem nenhum código a mais. Por quê? Para o visual, uma lista com display: grid e um cartão por item, com a borda de cima na cor do selo de cada status.

Para pensar

A API tem um endereço GET /api/resumo que devolve a mesma contagem. Se ela já existe, por que não usar? Em que situação a contagem feita no navegador passaria a dar errado?

Pense no que acontece quando a lista tiver milhares de solicitações e a tela só trouxer uma página delas. É o assunto de amanhã.

Antes de dar por pronto

Rode npm run lint e npm run build. Mude o status de uma solicitação e confira o resumo.
