API DO CURSO

Uma API REST fictícia, feita só para as aulas. NÃO é a API da Embasa.
Usa só o Node: não precisa instalar nada.

COMO USAR
1. Copie esta pasta (api-do-curso) para dentro de central-de-solicitacoes,
   ao lado da pasta src (e não dentro dela).
2. No VS Code, abra um terminal novo com o botão + (o primeiro continua com o npm run dev).
3. Rode:
     node api-do-curso/servidor.mjs
4. Teste no Chrome: http://localhost:3333/api/solicitacoes

Para parar: Ctrl + C no terminal da API.
Os dados ficam em memória: ao reiniciar, voltam ao estado inicial.
O que a API aceita e devolve está em CONTRATO.md.

Se aparecer "A porta 3333 já está em uso": a API já está rodando em outro terminal.
