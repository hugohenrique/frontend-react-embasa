API DA CENTRAL

Uma API REST do curso, com banco de dados SQLite. NÃO é a API da Embasa.
Usa só o Node (22.13 ou mais novo): não precisa instalar nada.

COMO USAR (é o que fazemos juntos na aula, slides 7 e 8)
1. Pare a API de ontem (Ctrl + C) e apague a pasta api-do-curso do projeto.
2. Copie esta pasta (api-central) para dentro de central-de-solicitacoes,
   ao lado da pasta src (e não dentro dela).
3. No package.json, dentro de "scripts", acrescente a linha:
     "api": "node api-central/servidor.mjs"
   (a linha de cima precisa terminar com vírgula)
4. Num terminal próprio do VS Code (botão +), rode:
     npm run api
   Sem o script, funciona também: node api-central/servidor.mjs

Na primeira vez, a API cria o banco em api-central/dados/central.db,
com 20 solicitações fictícias. Os dados ficam salvos entre um reinício e outro.
Para voltar aos dados iniciais: npm run api -- --reiniciar

O que a API aceita e devolve está em CONTRATO.md.
