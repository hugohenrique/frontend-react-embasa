O formulário de solicitações com React Hook Form

Faça com o FormularioSolicitacao o que fizemos com o de ordens, usando o esquemaNovaSolicitacao que você escreveu hoje:

  • Troque os useState dos campos por useForm com zodResolver(esquemaNovaSolicitacao) e register.
  • Mostre a mensagem de cada campo com errors, com o aria-invalid e o aria-describedby, como no formulário de ordens.
  • Na PaginaSolicitacoes, o registrar passa a devolver os erros da API, como o criar das ordens. Apague o validarNovaSolicitacao do regras.ts.
  • O botão não fica mais desabilitado até tudo estar preenchido: a pessoa clica e vê o que falta.

As três armadilhas

  • Os botões de rádio da prioridade: cada um recebe o seu value ("baixa", "media", "alta") e o mesmo register("prioridade").
  • A caixa “rua toda”: ela não vai para a API, então não é campo do esquema. Pode continuar num useState comum. Quando ela é marcada, a prioridade vira alta: procure o setValue na documentação do React Hook Form, e a opção shouldValidate, para o erro da prioridade sumir na hora.
  • O tipo e o contador do relato precisam do valor atual do campo enquanto a pessoa digita. Procure o useWatch na documentação.

Documentação: react-hook-form.com/docs/useform/setvalue e react-hook-form.com/docs/usewatch.

Antes de dar por pronto

Rode npm test (os testes do esquema continuam passando), npm run lint e npm run build. No Chrome: registre com tudo vazio, com o bairro “Pi” e prioridade alta sem relato, e uma solicitação certa.
