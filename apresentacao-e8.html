O valor do campo vem do estado.







  
Duas memórias, uma de cada um

  

    
O campo
O navegador guarda o que foi digitado, dentro do próprio campo.

    
O estado
O React guarda uma cópia, que o onChange atualiza.

  

  
O setBusca("") limpou a memória do React. A do campo ninguém mexeu.







  
Campo controlado: value e onChange

  

  

    
value
O campo mostra o que está no estado.

    
onChange
O que se digita vai para o estado.

Digita “c”
›

›
    
React redesenha
›
    
value mostra “c”

  

  
Quem manda no campo é o estado. Mudou o estado, por qualquer motivo, o campo muda junto.

As regras dos hooks

  

  
React Hook "useState" is called conditionally. React Hooks must be called in the exact same order in every component render.

  
Hooks sempre no começo do componente, nunca dentro de if, laço ou função. O Oxlint acusa em vermelho.
